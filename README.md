# CodeArya Digital Visions

## Getting started

Requirements: Node.js and npm.

```sh
# Install dependencies
npm i

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui (Radix UI)
- Tailwind CSS

## Project scripts

Refer to `package.json` for available scripts like `dev`, `build`, `preview`, and `lint`.
